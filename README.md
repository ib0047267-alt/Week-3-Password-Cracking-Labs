# Week 3 – Password Cracking Labs

## Cybersecurity & Ethical Hacking

This repository documents my Week 3 practical exercises with **Networkwalks**, focused on understanding password security and password recovery techniques.

### Module 1: Password Cracking with John the Ripper (JTR)

**Tools used:**
- John the Ripper (JTR)
- Johnny GUI

**What I learned:**
- Understanding password hashes.
- Extracting password hashes from protected PDF files.
- Using John the Ripper and Johnny to perform password recovery.
- Understanding how password complexity affects cracking time.

### Module 2: Password Cracking with Networkwalks Tools

**Tools used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker

**What I learned:**
- Extracting PDF password hashes using the Hash Calculator.
- Using dictionary-based password cracking.
- Recovering a password from an extracted hash.
- Understanding the importance of strong passwords.

### Key Takeaways

These practical exercises improved my understanding of password hashing, password recovery, dictionary attacks, and the importance of using strong passwords to protect sensitive information.
